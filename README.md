# AthleteAI – Landing Website

A modern, responsive landing website for **AthleteAI – AI-Powered Mobile Platform for Scalable Sports Talent Identification**, a Smart India Hackathon project.

## Design

- **Theme:** Innovative, technology-driven, sports-focused
- **Colors:** Dark blue (#0a1628), white, neon green (#00ff88) accents
- **Style:** Futuristic but minimal
- **Animations:** Framer Motion scroll-triggered fade-ins, staggered reveals, neon glow effects

## Sections

- Hero with primary CTAs
- Features (AI Video Analysis, Cheat Detection, Offline Mode, Benchmarking, Gamification, Secure Submission, Monthly Certificates)
- How it Works (Record → Analyze → Identify)
- Technology Stack
- Team
- Demo Video
- Testimonials
- Stats
- Call to Action
- Footer with Smart India Hackathon branding

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
```

Output in `dist/`.

## Customization

- **Team:** Edit `src/components/Team.tsx` to add real names and roles
- **Demo link:** Update `DEMO_URL` in `Hero.tsx`, `DemoVideo.tsx`, and `CTA.tsx`
